# AI 안전일지 자동입력 웹앱

카톡/현장에서 받은 공종별 작업사항을 웹 폼에 입력(또는 붙여넣기)하면, 엑셀 안전일지
(`안전일지(교도소 신축시설 현장) 남동현.xlsx`)에 오늘 날짜 시트를 자동 생성/갱신해주는 로컬 도구입니다.

## 주요 기능

- **카톡 붙여넣기 자동 채우기**: 카카오톡 단체방의 공종별 예정작업사항 메시지를 통째로 복사해서
  붙여넣으면, 공종별 인원/작업내용을 자동으로 인식해서 채워줍니다.
- **날씨 자동조회**: 평택시 팽성읍 좌표 기준 Open-Meteo API로 당일 날씨를 자동으로 가져옵니다.
- **전일 무재해시간 자동 연동**: 워크북에서 가장 최근 날짜 시트의 무재해달성시간(C5)을 실제 엑셀
  수식으로 실시간 연동합니다 (전날 값이 나중에 수정되면 오늘 시트도 자동 재계산됨).
- **안전지시사항 자동 제안**: 입력된 작업내용의 키워드(용접/절단, 에폭시/샌딩, S/L/타일, 굴착/양수 등)를
  분석해서 안전관계기록에 들어갈 표준 안전지시사항을 자동으로 제안합니다.
- **사진 3장 자동 삽입**: 사진을 복사한 뒤 폼의 사진 박스를 클릭하고 Ctrl+V로 붙여넣으면, 제출 시
  엑셀 사진대지의 정해진 위치에 자동으로 삽입됩니다.
- **오래된 시트 자동 보관**: 서버가 시작될 때마다, 가장 최근 시트를 제외하고 7일 넘은 날짜 시트를
  월별 보관 파일(`안전일지_보관_YYYY년 MM월.xlsx`)로 옮기고 메인 파일에서는 지워서 파일을 가볍게 유지합니다.
  (데이터는 삭제되지 않고 보관 파일에 그대로 남습니다.)
- **자동 백업**: 서버 시작 시 및 매 제출 직전, `backups/` 폴더에 타임스탬프 백업을 남깁니다 (최근 30개 유지).
- **Windows 로그인 시 자동 실행**: 시작프로그램에 등록해두면 컴퓨터를 켤 때마다 서버를 수동으로 켤
  필요 없이 창 없이(백그라운드) 자동으로 뜹니다.
- 사진대지 중 자동 삽입 이후의 산업재해 표 / 결재란은 자동으로 채우지 않고 비워둡니다 (사용자가 엑셀에서 직접 입력).

## 동작 방식

- PowerShell로 만든 로컬 웹서버(`webapp/server.ps1`)가 `http://localhost:8787` 에서 입력 폼을 서빙합니다.
- 제출하면 서버가 Excel을 COM으로 직접 제어해서, 워크북 안에 숨겨둔 `TEMPLATE` 시트를 복제 → 오늘 날짜로
  이름을 바꾸고 → 값을 채운 뒤 저장합니다. (별도 파일로 다시 저장(SaveAs)하지 않고 같은 파일을 그대로 저장합니다.)
- **파일은 요청을 처리하는 짧은 순간에만 열었다 바로 닫습니다.** 그래서 평소에는 사용자가 엑셀에서
  직접 파일을 열어 사진대지/산업재해/결재란 등을 수정할 수 있습니다. 다만 웹 폼이 실제로 파일을 열고
  저장하는 그 짧은 순간에는 엑셀에서 파일이 열려있으면 안 됩니다 (열려있으면 오류 메시지가 뜨고
  제출이 실패하니, 엑셀 창을 닫고 다시 시도하면 됩니다). 반대로 웹 폼 제출 중에는 엑셀에서 그 파일을
  열지 마세요.

## 필요 환경

- Windows + Microsoft Excel 설치 (COM 자동화를 사용하므로 필수)
- 원본 엑셀 파일: 이 저장소에는 포함되어 있지 않습니다 (`.gitignore` 처리). 실제 파일을 이 폴더
  (`AI 안전일지 생성/`) 바로 아래에 함께 두어야 합니다.

## 최초 1회 설정

원본 엑셀 파일에 `TEMPLATE`이라는 숨김 시트가 없다면(새 PC로 파일을 옮겨왔을 때 등) 한 번만 실행:

```
webapp\PrepareMasterTemplate.ps1
```

기존 시트 하나를 복제해서 사진/서명 이미지는 제거하고, 가변 항목은 비운 뒤 `TEMPLATE`이라는
매우 숨김(very hidden) 시트로 저장해둡니다. 이미 있으면 아무것도 하지 않습니다.

## 실행

`webapp\run.bat` 더블클릭 → 서버가 뜨고 자동으로 기본 브라우저가 `http://localhost:8787` 로 열립니다.
(index.html 파일을 직접 더블클릭해서 열면 안 됩니다 — 서버를 거치지 않으면 날씨 조회/저장 등 모든
기능이 실패합니다.)

### 로그인할 때마다 자동으로 켜지게 하기

Windows 시작프로그램 폴더(`Win+R` → `shell:startup`)에 `webapp\start_server_silent.vbs`의 바로가기를
넣어두면, 로그인할 때마다 콘솔 창 없이 조용히 서버가 백그라운드에서 시작됩니다. 브라우저에서
`http://localhost:8787` 로 들어가면 바로 쓸 수 있습니다. 자동 시작을 끄고 싶으면 시작프로그램 폴더에서
그 바로가기만 지우면 됩니다 (서버 파일 자체는 그대로 둬도 됨).

## 폴더 구조

```
AI 안전일지 생성/
├── 안전일지(교도소 신축시설 현장) 남동현.xlsx   ← 원본 (git에는 없음, 직접 위치시켜야 함)
├── 안전일지_보관_YYYY년 MM월.xlsx              ← 7일 지난 시트 자동 보관 파일 (자동 생성됨, git에는 없음)
├── backups/                                    ← 자동 백업 (git에는 없음)
└── webapp/
    ├── index.html                  입력 폼 UI
    ├── server.ps1                  로컬 서버 + 엑셀 자동화 본체
    ├── Weather.ps1                 날씨 자동조회
    ├── PrepareMasterTemplate.ps1   최초 1회 TEMPLATE 시트 생성 스크립트
    ├── run.bat                     실행 스크립트 (수동 실행용)
    └── start_server_silent.vbs     로그인 시 자동 실행용 (창 없이 백그라운드 시작)
```

## 알려진 제약

- 공종 행은 최대 8개까지 지원 (엑셀 서식상 고정 슬롯). 기본: 직원, 직영, 전기/ESS, 기계설비/가스,
  수장, 도장, 토목, 펜스.
- 장비 점검 항목은 최대 5개까지 입력 가능. 사진은 3장까지.
- 안전지시사항 자동 제안은 정해진 키워드 목록에만 반응하는 단순 규칙 기반이라, 목록에 없는 특이
  작업은 자동으로 못 잡아냅니다 (제출 전 항상 확인 필요).
- 아이패드 등 Windows/Excel이 아닌 환경에서는 이 방식(로컬 PowerShell + Excel COM) 자체가
  동작하지 않습니다. 다른 기기에서 쓰려면 실제 웹 서버 + 클라우드 엑셀 API 기반으로 재설계가 필요합니다.
