# AI 안전일지 자동입력 웹앱

카톡/현장에서 받은 공종별 작업사항을 웹 폼에 입력하면, 엑셀 안전일지(`안전일지(교도소 신축시설 현장) 남동현.xlsx`)에
오늘 날짜 시트를 자동 생성/갱신해주는 로컬 도구입니다.

## 동작 방식

- PowerShell로 만든 로컬 웹서버(`webapp/server.ps1`)가 `http://localhost:8787` 에서 입력 폼을 서빙합니다.
- 제출하면 서버가 Excel을 COM으로 직접 제어해서, 워크북 안에 숨겨둔 `TEMPLATE` 시트를 복제 → 오늘 날짜로
  이름을 바꾸고 → 값을 채운 뒤 저장합니다. (별도 파일로 다시 저장(SaveAs)하지 않고 같은 파일을 그대로 저장합니다.)
- 날씨는 평택시 팽성읍 좌표 기준으로 Open-Meteo에서 자동 조회합니다.
- 전일 무재해시간은 워크북에서 가장 최근 날짜 시트를 찾아 자동으로 이어받습니다.
- 사진대지 / 산업재해 표 / 결재란은 자동으로 채우지 않고 비워둡니다 (사용자가 엑셀에서 직접 입력).

## 필요 환경

- Windows + Microsoft Excel 설치 (COM 자동화를 사용하므로 필수)
- 원본 엑셀 파일: 이 저장소에는 포함되어 있지 않습니다 (`.gitignore` 처리). 실제 파일을 이 폴더
  (`AI 안전일지 생성/`) 바로 아래에 함께 두어야 합니다.

## 최초 1회 설정

원본 엑셀 파일에 `TEMPLATE`이라는 숨김 시트가 없다면(새 PC로 파일을 옮겨왔을 때 등) 한 번만 실행:

```
webapp\PrepareMasterTemplate.ps1
```

기존 시트 하나를 복제해서 사진/서명 이미지는 제거하고, 가변 항목은 비운 뒤 `TEMPLATE`이라는
매우 숨김(very hidden) 시트로 저장해둡니다. 이미 있으면 아무것도 하지 않습니다.

## 실행

`webapp\run.bat` 더블클릭 → 브라우저에서 `http://localhost:8787` 접속.

(엑셀 COM 자동화 특성상, 서버가 켜져 있는 동안은 원본 엑셀 파일을 다른 프로그램에서 동시에
열어 편집하지 마세요. 파일이 이미 열려 있으면 서버가 읽기전용으로 열려 저장에 실패하고 종료됩니다.)

## 폴더 구조

```
AI 안전일지 생성/
├── 안전일지(교도소 신축시설 현장) 남동현.xlsx   ← 원본 (git에는 없음, 직접 위치시켜야 함)
└── webapp/
    ├── index.html                  입력 폼 UI
    ├── server.ps1                  로컬 서버 + 엑셀 자동화 본체
    ├── Weather.ps1                 날씨 자동조회
    ├── PrepareMasterTemplate.ps1   최초 1회 TEMPLATE 시트 생성 스크립트
    └── run.bat                     실행 스크립트
```

## 알려진 제약

- 공종 행은 최대 8개까지 지원 (엑셀 서식상 고정 슬롯).
- 장비 점검 항목은 최대 2개까지 입력 가능.
- 아이패드 등 Windows/Excel이 아닌 환경에서는 이 방식(로컬 PowerShell + Excel COM) 자체가
  동작하지 않습니다. 다른 기기에서 쓰려면 실제 웹 서버 + 클라우드 엑셀 API 기반으로 재설계가 필요합니다.
